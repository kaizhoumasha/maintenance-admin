# SMT 手工货架异常收口修复计划

依据：本轮关于 RETURN/TRANSFER 进出场、成员撤销及进场 Transport CANCELLED 的讨论，以及 `docs/testing/smt-manual-kt16-kt18.md` 当前失败记录。仅在原工作区实施，不提交、不部署。

## 约束与验收

- 保持公开 WMS/ECS/Transport 合同与业务边界；复用现有 sorting_task、BIN_Roller、Transport，不增加表、迁移或通用状态机。
- 原请求、原 Transport、结果版本和冻结意图保持。不能伪造进场成功、朝向、任务完成；不能静默重建进场。
- 本轮为高风险业务状态修复。先复现失败再修；控制器独占可丢弃测试资源并管理状态性验收。工作区原暂存/未暂存内容必须保留，评审以本轮增量为准。
- 正常 TRANSFER 退场仍等任务 COMPLETED；RETURN 无剩余有效作业即问 WMS 退场，不等无意义的人工完工。公共报告、原释放、其他货架义务独立履约。
- Transport CANCELLED 只代表原搬运终结。只消费可信已应用结果，无未决结果、更新位置观测或前序义务才能作资源判断。目标位之外若落在其他受管点，不能直接当成无占位。
- 所有实际网络请求仅 loopback/mock，不联系工厂端点。KT16、KT18 必须各自独立，RETURN OUT55/56，TRANSFER OUT65/66；容量规则不变。

## Task 1: 修复货架取消、离场和完成收口并补齐回归

范围：`app/businesses/smt_manual/manual_rack_flow.py`、必要的 `task_flow.py`/`service.py`，现有 SMT 测试及必要共用 fixture。不改平台 Transport 判定，不改 BIN_Roller 额度释放语义。

1. 根因核对：追踪 reconcile、result consumption、advance、member cancel、completion readiness、pending scan 及 archive/role occupancy 查询，列明所有受影响调用点。
2. TDD：先在永久测试中复现 ZONE 退场成功但终位仍在原工作点的错误释放，以及进场 CANCELLED 在目标点/目标外长期等待的问题。断言业务占位、任务完成和原意图数量，而非只断言私有状态名。
3. 离场收口：即使目标为 ZONE，可信终位仍为原 RACK_POSITION 也不能 DEPARTED；保留占位和冲突。确已离开原点且满足原结果/前序条件才释放。明确 RACK_POSITION 目标仍严格匹配，已知位置的取消/失败不得伪装成功。
4. 进场取消：
   - 可信终位在目标位外且无受管占位冲突：结束本次进场等待、解除进场预留。仍有效的成员/目标任务保持未履约、需要恢复，不自动创建新 ENTER；若关联直接取料明细均已有效撤销，不能因此永久阻塞任务完成。
   - 终位在目标位且 RETURN 关联作业全部有效撤销：保持占位，走原 WMS departure WAIT/READY 流程，current_face=null，不造 arrival_report。
   - 在目标位且仍有有效成员或转运目标义务：保持占位及未履约，显式返回需要恢复的进度，不沿正常成功进场继续作业或伪造 COMPLETED；本轮不新增恢复接口。
   - 未知/冲突/未决或有更新观测：保留 pending 与资源保护，不释放、不重复发命令。更新观测保留待核对；不得把观测直接改为已应用结果。
5. 撤销：仅实际有效的 member 撤销影响剩余作业，已开始成员保留；部分撤销继续余项。进场还在运行时保持原 Transport，成功到位后全部撤销则立即问退场。TRANSFER 不受 direct-member selector 越权撤销。
6. 完成与推进：业务任务完成、原 Transport 终结、角色占位解除分开。防止取消结果导致永久 WAITING_FOR_ENTRY、无依据完成、自动再叫架；已完成/有未结公共义务的原任务仍可恢复推进。复用平台 owner 通知和 Beat，不新增任务/显式唤醒。
7. 测试矩阵：两线两角色 ZONE 同源终位和正常异位；CANCELLED 目标内/目标外/其他受管点；有效成员/全部撤销/部分撤销/STARTED；取消与原到位先后；WAIT 到期、重复/并发推进不重复建动作；未知/新观测与未决结果；转运目标不虚假完成；另一线继续；报告义务不丢失。现有合同对 CANCELLED 无终位/携带朝向的拒绝复用原测试，不改变协议。

报告：列根因、增量文件、失败到通过证据、检查命令及实际结果、尚未验证风险。禁止提交、暂存、部署、派生子代理。控制器提供测试资源；不得自行连接默认数据库或运行全仓状态性测试。
