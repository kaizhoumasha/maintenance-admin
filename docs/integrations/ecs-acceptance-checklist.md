# 真实 ECS 接入验收清单

**状态：未启动；不属于本批次开发范围。** 本文承接原教程开发PLAN的Task 10，不再作为开发任务计数。ECS通用能力、Swagger及最小业务示例的本方隔离验收已结项；没有选定实际对端和接入环境时，不要求填写现场值，也不启动验证。

用途是接入某个实际ECS时核对适配条件，不是本项目的生产部署计划。供应商协议核对可以在对端测试环境完成；具体部署、现场执行与生产切换必须在明确环境后另定联调/上线计划，并分别授权。不能凭本清单存在或框架测试通过就发送真实命令。

## 责任与使用时机

| 类别 | 本项目开发阶段 | 实际接入阶段 |
|---|---|---|
| 协议与安全约束 | SPEC固定W=300秒、冻结身份/地址/期限、事务/幂等、UNKNOWN/HELD，并通过隔离测试 | 对照实际版本核验，不为某个供应商静默放宽框架合同 |
| 供应商符合性 | 定义最低要求，不声称已取得对端证据 | 对端测试环境核验字段、ACK/错误、去重保留、跨重启恢复；明确实际版本及责任人 |
| 本项目接入实现 | 设备管理/路由适配、真实业务许可、来源控制等有需求时另定范围，不全部归给供应商 | 本项目落实实现，双方确认鉴权/网络，记录实际生效证据 |
| 现场与上线 | 不预填地址、不编排生产操作，不阻塞本方隔离开发结项 | 选定环境后制定部署、停止/恢复、备份/回退、执行许可与物理验收计划，另行批准 |

最低合同与行为依据见[ECS接入参考](ecs-command.md)及[教程设计§10.4](../superpowers/specs/2026-10-25-ecs-minimal-business-tutorial-design.md)。W从本方首次创建起算，D从对端持久确认确定终态起算至少24小时；活动/未决去重依据不按TTL清理，跨重启/断电须保留原接纳事实。旧调用重入与存量冻结期限不重算；ACK/在线/IDLE不代表物理或业务完成；UNKNOWN/HELD不自动重发、改投或解封。

## 接入时核对（原Task 10三项完整保留）

以下未勾选表示该真实接入验收未启动，不表示开发批次欠交付；未确认值不猜。选定具体ECS和环境后，再记录版本、责任人、证据及结论，不能预填“通过”。

- [ ] 确认实际scheme/IP/port、全系统唯一DEVICE_CODE、动作、params/data/error、附录id/version、timeout、供应商ACK/错误/429、跨重启去重保留期及允许重试窗口、TLS/鉴权。核实实际版本符合已批准W=300秒、D=确定终态后至少24小时、活动/未决不按TTL清理及跨进程/主机/断电恢复的最低合同，取得保留配置/持久记录/原身份重复与冲突及物理行为证据；不能以Mock、加速时钟或本方测试替代真实对端符合性；正式业务另校验动作语义与业务许可，不要求Swagger逐动作登记，不使用测试窗口冒充真实保证，不新增ECS表或兼容协议层。

- [ ] 核实专用权限、现场执行许可、设备/动作/窗口、停止核对、回报网络及Result来源控制、原附录/证据留存、发布/备份/迁移回退；Swagger登录、online/IDLE或可达都不替代。未满足真实条件时不得开始现场发送；停止Sender不代表取消在途或设备急停，同服务Result停机/对端重报须明确。

- [ ] 单独取得本次真实发送批准后才安排单设备/单动作现场联调，记录原身份和合法真实Result，不手工伪造完成。ACK不等于物理/业务成功，UNKNOWN/HELD不自动重放/改投；异常先停后核对，现场与离线分别留证。

## 验收结论边界

框架隔离测试只能证明本方机制；实际对端的持久去重与跨重启保证、网络/来源限制和物理行为须分别取证。若对端不满足最低合同，应记录差异并另行决策，不恢复旧协议兼容层、地址清单、联网开关或逐动作手工注册。此清单不新增ECS配置表，不安排自动重发或结果纠正。
