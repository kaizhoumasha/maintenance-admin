# SMT 自动出库扫码补扫改造与联调清单

适用范围为 SMT 自动出库的料箱取盘（BIN）和退料架储位取盘（RackSlot）。料盘已到扫码平台但首扫未读到时，ECS 自动补扫，达到上限后报警并等待人工复扫。WES 收齐原取盘成功结果和本盘实读条码后，才向 WMS 请求本盘去向。

## ECS / PLC 改造项

- [ ] **原盘补扫。** 扫码器返回 `NoRead` 后，在同一平台对同一盘重新触发扫码，沿用原取盘 `command_code`。为自动补扫设置次数和总耗时上限，由现场联调确定数值。扫码失败期间由设备侧记录尝试与报警。
- [ ] **平台互锁。** 自动补扫、报警和人工处理期间保持平台占用，拦住后续盘进台。解除报警或复位设备后，平台仍按实物状态互锁，直到原盘按 WES 授权实际离开平台。
- [ ] **报警后人工复扫。** 到达任一上限后停止自动尝试并报警。HMI 提示扫码平台、原取盘指令和失败原因。操作员按设备安全流程处理原盘并触发复扫，读到条码后 ECS 上报同一盘的扫码事件。人工仍读不到时，保持待处理，按现场流程联系仓库处理。
- [ ] **持久化与补报。** 重启后恢复原取盘指令、平台占用、扫码阶段、已用补扫次数与时间，以及未确认上报的原报文。实物与原指令无法可靠对应时，保持互锁并报警，等人工核对。重传事件沿用原版本、原扫码时间和原正文。

## 回调合同

| 事实 | 现有接口 | 上报要求 |
| --- | --- | --- |
| 原盘实际放到扫码平台 | `POST /api/v1/callback/result` | 至少满足原 `command_code`、取盘机械臂 `device_code`、真实 `finish_time`、`result=SUCCESS`、`actual_qty=1`、`pick_and_put_result=PUT_FINISHED`。新流程由独立扫码事件上报条码，机械臂 Result 可省略 `barcode` 和 `scanned_at`。 |
| 原盘读码成功 | `POST /api/v1/callback/event` | 由工作线绑定的扫码设备发 `SCAN_COMPLETED`，`location=SCAN_PLATFORM`，`previous_command_code` 为原取盘命令号，`barcode` 为实读原文，顶层 `timestamp` 为实际扫码时间（UTC Unix 毫秒）。 |

新流程在第一次读到真实条码时上报 `scan_revision=1`（也可省略，默认 1）。自动和人工扫码尝试次数由设备侧记录。仍使用旧回报方式的设备若已上报第 1 版 `NoRead`，首次补扫真码应沿用原取盘指令，使用下一连续版本和新的实际扫码时间。两类回调允许乱序。HTTP ACK 表示回调已接收，联调还需核对回调是否关联原盘以及是否生成 WMS 判定。

原机械臂 Result 已成功时，后续人工复扫只补扫码事件。设备若仍处于原命令的可恢复阶段，按设备安全流程恢复未完成阶段。已经发出终态 `FAILED` 的命令，后续按原失败流程核对处置。

## 联调验收项

以下场景分别在 BIN 和 RackSlot 验证。每条记录工作线、原取盘指令号、设备端报警或扫码日志、回调报文，以及对应的 WMS 请求或无请求的核对结果。

| 场景 | 验收结果 |
| --- | --- |
| 首扫成功 | 原取盘结果与扫码事件都到齐后，WES 发送一次首次物料判定，条码和扫码时间与实读一致。 |
| 自动补扫成功 | 失败尝试期间平台保持占用，WES 没有物料判定。补扫真码关联原取盘，WES 发一次首次判定。 |
| 补扫耗尽后人工复扫成功 | ECS 报警并停止自动尝试，下一盘不能进台。人工复扫通过原指令恢复本盘，WES 用真码发一次首次判定。 |
| 人工仍无法读码 | 原盘继续等待，下一盘仍被互锁拦截，WES 无物料判定、NG 搬运或移库报告。 |
| 回调乱序、重传或旧盘误报 | 任一事实先到都等待另一条。相同报文重传不产生重复判定，旧盘回调不会推进当前盘。 |
| 设备重启 | 覆盖补扫中、待人工和读码成功待上报三个阶段。按原指令和原报文恢复，重启期间平台互锁有效。 |
| 旧 ECS 版本化补扫 | 第 1 版 `NoRead` 后补报下一连续版本的实读码。WES 留存前序回报，用最后实读码发首次判定。另验证 RackSlot 原 Result 中的 `NoRead` 可由同指令的首个实读扫码事件恢复。 |
| 真码被 WMS 判 NG | 原 NG 放盘成功后，移库报告带本盘实读条码、实际 NG 位置和放盘完成时间。 |

切换顺序为先上线 WES 拦截与兼容逻辑，再逐线启用 ECS 自动补扫。切换前核对已经发起 WMS 判定或已下发 NG 放盘的旧盘，按原指令和原请求证据收口。
