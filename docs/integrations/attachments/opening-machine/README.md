## 当前主例：0.5% 整层投料 NG 概率

使用 `requested=2500`、`seed=88`、`pattern=random`、`ng_profile=0.5pct`、`timing=lower_slow`、`policy=paired_whole`。在原模拟器的 NG 概率表中增加 `'0.5pct': 0.005`，其余调度、容量、随机流和等待规则不变。每次补取也适用同一概率，等板及可恢复等待不计为 NG。

| 项目 | 上盖 | 下盖 |
|---|---:|---:|
| 成功量 | 2500 片 | 2500 片 |
| 实际取出 | 2510 片 | 2518 片 |
| 已确认投料 NG | 5 层，10 片 | 9 层，18 片 |
| 供箱 | 207 箱 | 282 箱 |
| 最大成功供料领先 | 22 片 | 14 片 |
| 最终余量 | 取料位 U207：2 片 | 缓存 L282：4 片 |

共 489 次供箱、489 次额度结算、2514 次取层。其中成功 2500 层、确认 NG 14 层，实际样本比例 `14 / 2514 ≈ 0.557%`。0.5% 是每次尝试的概率，不要求单次样本恰好达到该比例，也不代表对现场质量的实测。两侧实际取出均等于成功加确认 NG，无超量或来源死锁；收尾后仍有来源余箱待清场。

已核对完整轨迹与仅保留末段轨迹的模拟器执行结果，全部汇总指标一致。该验证只覆盖本次样本，未重跑完整 9472 组历史主推演。

## 无 NG 对照及定点异常样本

正常流程使用 `requested=2500`、`seed=88`、`pattern=random`、`ng_profile=none`、`timing=lower_slow`、`policy=paired_whole`。箱容量与随机流保持原定义，只取消 NG 注入；实际箱内量仍按完整层随机。正常流程说明设为无 NG，不代表承诺现场 NG 率为零。

| 项目 | 上盖 | 下盖 |
|---|---:|---:|
| 成功量/实际取出 | 2500 / 2500 片 | 2500 / 2500 片 |
| 已确认投料 NG | 0 片 | 0 片 |
| 供箱 | 206 箱 | 281 箱 |
| 最大成功供料领先 | 22 片 | 14 片 |
| 最终余量 | 缓存 U206：4 片 | 取料位 L281：6 片 |

正常流程共有 487 次供箱、487 次额度结算和 2500 次成功取层，无补取、无超量、无来源死锁。设备内部等板及同层等待不计为 NG；模型保留有限内部等待，不用于估计现场节拍。

定点异常使用 `ng_profile=last_layer_once`，只让上下盖各自最后一层 NG 一次。两侧各取出 2502 片，其中成功各 2500 片、确认 NG 各 2 片；各补 1 层，没有超量。该场景不假设随机 NG 率。

两组均于 2026-11-05 运行并验证数量平衡。无 NG 的完整轨迹另与不增加轨迹记录的原模拟器执行结果比较，全部汇总指标一致。它们作为对照与定点补取验证保留；当前主例已改为 0.5% 输入。原 25% 样本继续作为压力证据保留，现场实际 NG 率待现场质量统计提供。

## 压力样本参数与口径

- `requested=2500`，`seed=88`，`pattern=random`，`ng_profile=25pct`，`timing=lower_slow`，`policy=paired_whole`。
- 上盖箱数量在 1-11 层中随机，下盖箱在 1-8 层中随机；每层 2 片。Python 标准库 `random.Random` 独立生成每侧箱序列、NG 序列及设备等待。
- 上下盖的来料随机流分别使用种子 `seed*2+1000003`、`seed*2+1000004`；NG 流使用 `seed*2+3000003`、`seed*2+3000004`；设备流使用 `seed*2+4000003`、`seed*2+4000004`。
- 25% NG 是压力条件，不代表现场故障率。模型只使用完整层，不含单片失败或单片不满层。
- 同层等待重试 0-3 次，之后才产生成功或终局 NG；NG 再等待确认。所有等待为有限模型时间，不是现场秒数。
- 模型假定空箱能在有限时间内退出，Buffer 内部等待可恢复、尾料收尾可完成。没有模拟 Buffer 内部 Magazine 有限资源的全部占用关系。
- 每层记录的“出料=1”表示该层 2 片已成功投到载板；箱级“出料=1”表示本箱至少有一层成功。两者均不代表 Magazine 已离场或 AGV 已交付。
- `tail_padding_layers` 是示例成品 Magazine 的待补空板层位数。Buffer 实际空板块数与层位的关系需硬件方确认。
- 轨迹末尾的收尾校验时刻是模型最终检查时刻，不能作为真实 Buffer 完成时间或节拍依据。
